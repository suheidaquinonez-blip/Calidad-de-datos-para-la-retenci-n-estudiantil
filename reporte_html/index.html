01Problema del negocio

Una institución de educación superior quiere saber qué factores se asocian a la deserción para diseñar estrategias de retención tempranas. Antes de analizar, hay que garantizar que los datos sean confiables.

Pregunta clave: ¿qué características tienen los estudiantes con mayor riesgo de abandonar sus estudios?

Ruta: conocer el dataset → auditar → limpiar y justificar → crear variables → graficar → responder → reflexionar.

06Reflexiones

1. Asociación y causalidad

Los becados desertan menos, pero eso no prueba que la beca cause la permanencia. Puede que se asigne a estudiantes que ya eran más comprometidos, o que influya algo no medido, como el apoyo familiar. Para distinguirlo habría que comparar grupos parecidos o dar la beca al azar.

2. Variables que no deben usarse para predecir

motivo_retiro solo existe después de que el estudiante se va: usarla sería darle la respuesta al modelo (data leakage). Sirve para entender por qué se van (el motivo económico es el más frecuente: 1.011 de 3.273), no para predecir. Lo mismo pasa con estado.

3. Variables sensibles

Género, estrato y ciudad pueden reflejar desigualdades. Usarlas para decidir quién recibe apoyo puede discriminar o estigmatizar. Es mejor basarse en variables sobre las que se puede actuar, como la asistencia.
